# sinkhive

Sink HTML/Markdown hive fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/sinkhive/

## Install / run

```bash
git clone https://github.com/theworker02/sinkhive.git
cd sinkhive
node src/cli.js
node --test
```
